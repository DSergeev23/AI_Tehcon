AWS запустила Textract Insights для обработки комплектов документов

Автор: AI TehCon

Новый API разделяет комплект документов, определяет их типы и извлекает заданные поля. При внедрении важно проверить языковую и региональную доступность.

2 минут

20 ноября AWS объявила об общей доступности Amazon Textract Insights — API для обработки документов с применением генеративного ИИ. Сервис может разделить один файл на отдельные документы и вернуть структурированные данные с указанием, где найдено каждое значение. Для компаний это способ сократить число отдельных компонентов в процессе обработки входящих документов, но качество извлечения нужно проверять на собственных файлах. AWS

Как устроена обработка

Компания описывает нужные поля в шаблоне на основе JSON Schema: например, номер договора или сумму счёта. Затем асинхронный запрос передаёт файл из Amazon S3. Textract Insights может разделить смешанный комплект, сопоставить части с шаблонами и записать результат обратно в S3. Для извлечённых полей сервис возвращает оценку уверенности и ссылку на область исходной страницы. Документация AWS

Практический сценарий — входящий пакет из заявлений, счетов и приложений, который затем нужно перенести в учётную систему. Редакционный вывод: перед автоматической записью стоит определить обязательные поля, пороги уверенности и маршрут ручной проверки. Наличие ссылки на страницу помогает проверить ответ, но само по себе не доказывает, что он верен. AWS

Условия и ограничения

На дату анонса Textract Insights доступен в двух регионах AWS в США: US East (N. Virginia) и US West (Oregon). AWS перечисляет шесть поддерживаемых языков документов — английский, французский, немецкий, итальянский, португальский и испанский; русского в списке нет. Доступ предусмотрен через API, оплата — за страницу. До внедрения следует проверить стоимость на реальном объёме и требования к размещению данных. Доступность, условия работы

AI TehCon занимается анализом и автоматизацией бизнес-процессов, включая работу с 1С. Если документы приходится вручную переносить в учётную систему, можно обсудить, какие поля и проверки нужны для такой интеграции.
