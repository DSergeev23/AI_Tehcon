Microsoft открыла предварительный доступ к Copilot harness в Foundry

Автор: AI TehCon

Разработчики получили управляемую среду для AI-агентов с инструментами и навыками. Сейчас это публичная предварительная версия с ограничениями по регионам и моделям.

2 минут

28 октября Microsoft открыла публичный предварительный доступ к Copilot harness в Foundry Agent Service. Это управляемая среда для AI-агентов, которые выполняют последовательность действий с файлами и подключёнными инструментами. Для IT-команд новость означает возможность испытать агентный процесс без самостоятельного обслуживания его среды выполнения.

Что делает среда

В обычной схеме модель получает запрос и возвращает ответ. Для многошаговой задачи ей дополнительно нужны рабочий контекст, доступ к инструментам и правила выполнения. Copilot harness берёт на себя координацию этих шагов и изолированную среду работы; разработчик задаёт инструкции, навыки, инструменты и подходящую модель. Microsoft описывает поддержку подключённых инструментов, файлов и ограниченного делегирования задач другим агентам. Отраслевое издание Visual Studio Magazine подтвердило выпуск среды через Foundry, но не приводило независимых испытаний её надёжности.

Ограничения для внедрения

Публичная предварительная версия не имеет соглашения об уровне сервиса и не рекомендована Microsoft для производственных нагрузок. Среду можно выбрать при создании нового агента; переключить уже созданного агента на неё пока нельзя. Поддержка ограничена девятью перечисленными регионами Azure. Российского региона в этом списке нет. Для этой версии требуется поддерживаемая модель с рассуждением и вызовом инструментов; подключение собственной модели пока не поддерживается. Поэтому общее заявление Microsoft о широкой поддержке моделей в семействе Copilot harness не следует автоматически переносить на возможности этой предварительной версии.

При оценке агента для закупок, обработки заявок или работы с 1С стоит отдельно проверить доступность нужного региона, права инструментов и поведение при прерывании задачи. AI TehCon можно пригласить обсудить процесс и точки интеграции до выбора платформы.
