Anthropic выпустила Claude Haiku 5.5 для массовых AI-задач

Автор: AI TehCon

Новая компактная модель Claude доступна через API Anthropic и облачные платформы. При выборе модели для массовой обработки документов и обращений бизнесу стоит считать стоимость целого сценария, а не одного запроса.

3 минут

7 октября Anthropic выпустила Claude Haiku 5.5 — модель для задач, где важны скорость и стоимость большого числа запросов. Она уже доступна через Claude API и облачные платформы, включая Amazon Bedrock; это позволяет проверить её на действующих процессах, а не только по результатам тестов разработчика. Anthropic, AWS.

Где может пригодиться модель

Anthropic предлагает Haiku 5.5 для коротких повторяющихся операций: классификации, поиска сведений в документах и подготовки кратких сводок. Для бизнеса это повод испытать модель, например, на сортировке входящих обращений или извлечении полей из документов. Пригодность для конкретного процесса покажет проверка на собственных данных: заявленные компанией результаты тестов не доказывают точность в другой предметной области. Anthropic.

В Claude API модель вызывается как claude-haiku-5-5. У неё есть настройка усилия обработки запроса (effort), позволяющая подбирать баланс между качеством ответа и расходом ресурсов. Документация Claude Platform.

Как считать затраты и планировать переход

По опубликованному тарифу Anthropic для запросов до 100 тысяч входных токенов цена составляет $0,10 за миллион входных и $0,50 за миллион выходных токенов. Для более длинных запросов ставки выше — $0,50 и $2,50 соответственно. Поэтому при оценке расходов нужно учитывать длину документов, объём ответов и число повторных вызовов, а не переносить на свой процесс общую оценку Anthropic о снижении стоимости работы модели. Anthropic.

Замена Haiku 4.5 в существующей интеграции требует проверки кода. Anthropic предупреждает, что некоторые прежние параметры запроса возвращают ошибку с Haiku 5.5; на Amazon Bedrock для этой модели пока недоступен режим структурированного вывода. Доступность в конкретном регионе и возможности выбранного облачного интерфейса также стоит проверить до миграции. Документация Claude Platform, документация AWS.

AI TehCon помогает разбирать бизнес-процессы и проектировать AI-интеграции с корпоративными системами. Если вы оцениваете модель для массовой обработки запросов или документов, можно обсудить критерии пилота и место проверки результатов человеком.
